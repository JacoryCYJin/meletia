# Meletia

Meletia 是一款离线桌面词汇学习工具。它按「词书 → 每日新词 → 组内循环 → 拼写 → 间隔复习」推进，而不是把卡片堆成一个到期队列。

## 学习怎么走

1. 导入 CSV 后按「来源」自动分到词书。多本词书可以同时启用，新词按书轮流出现，一张卡只学一次。
2. 每天先复习再学新词：上次没答对的词先回炉，其次是按间隔到期的词。
3. 学新词时先完整看一遍释义和例句；第二遍起遮住释义回忆，一组最多 10 个，答对 4 次才进复习。
4. 一组结束做拼写，拼错的词会排到下次复习前面。
5. 复习只判断三档，见下。

## 复习规则

复习时先只给单词，自己判断，不先看答案：

| 选择 | 行为 |
|---|---|
| 认识 | 直接下一个词，不展开释义 |
| 模糊 | 展开释义、词组和例句，看完点「下一个」；间隔退一档 |
| 不认识 | 展开释义，看完点「下一个」；回到第一档，并排进回炉队列 |

间隔是一条约 120 天的阶梯：1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 天。认识前进一档，模糊退一档，不认识回到起点。走到 60 天以上记为「已掌握」。

这条阶梯不是官方公开参数，是按不背单词宣称的艾宾浩斯曲线和「x 天后出现」的行为还原的近似实现。

每日新词量、每组词量和答对次数在「词书」页调整。空格翻面，数字键评分。

## 数据

词库、词书和复习记录保存在 macOS 的 `~/Library/Application Support/com.jacoryspace.meletia/library.json`。

## 开发与打包

在 Mac 上准备 Xcode 命令行工具、Rust 和 Node.js 20 或更新版本，然后执行：

```sh
npm ci
npm test
npm run tauri dev
npm run tauri build -- --bundles app,dmg
```

应用和磁盘映像位于 `src-tauri/target/release/bundle/`。开发构建用于本机试用。公开分发前按 Apple 的要求设置签名与公证。
