# Meletia

Meletia 是一款离线桌面词汇学习工具。它按「词书 → 每日新词 → 组内循环 → 拼写 → 间隔复习」推进，而不是把卡片堆成一个到期队列。

## 学习怎么走

1. 导入词表时确认首行和列映射，再选择已有词书或用文件名新建。再次导入同一本词书时只追加新词。每张卡片属于一本词书，不同词书的同词卡片各自记录进度。多本词书可以同时启用，新词按书轮流出现。
2. 每天先复习再学新词：上次没答对的词先回炉，其次是按间隔到期的词。
3. 新词先选释义，隔几题再无提示回想。选项不足时先看一次释义。答错时查看释义，再重做当前题型。
4. 整组辨识结束后可开始或跳过拼写。拼错的词会排到下次复习前面。
5. 复习先判断熟悉程度，模糊或忘记的词在同组补考。

## 复习规则

复习时先只给单词，自己判断，不先看答案：

| 选择 | 行为 |
|---|---|
| 认识 | 直接下一个词，不展开释义 |
| 模糊 | 看完详情后，继续做释义选择和看中文回想英文。完成后间隔退一档 |
| 忘记了 | 做完同组补考后，按最短间隔重新排期 |

间隔是一条约 120 天的阶梯：1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 天。认识前进一档，模糊退一档，不认识回到起点。走到 60 天以上记为「已掌握」。

这条阶梯不是官方公开参数，是按不背单词宣称的艾宾浩斯曲线和「x 天后出现」的行为还原的近似实现。

每日新词量、每组新词量和每日复习上限在左下角「设置」调整。用数字键选答案或自评，答后按空格或回车继续。

## 数据

词书、卡片和复习记录保存在 macOS 的 `~/Library/Application Support/com.jacoryspace.meletia/library.json`。删除词书会删除书里的卡片和复习记录。合并前可以预览重复数，同词保留目标书的释义和进度。

## 开发与打包

在 Mac 上准备 Xcode 命令行工具、Rust 和 Node.js 20 或更新版本，然后执行：

```sh
npm ci
npm test
npm run tauri dev
npm run tauri build -- --bundles app,dmg
```

应用和磁盘映像位于 `src-tauri/target/release/bundle/`。开发构建用于本机试用。公开分发前按 Apple 的要求设置签名与公证。
