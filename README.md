# Meletia

Meletia 是一款离线桌面词汇学习工具。它按「词书 → 每日新词 → 组内循环 → 拼写 / 听写 → 间隔复习」推进，而不是把卡片堆成一个到期队列。

## 学习怎么走

1. 导入词表时确认首行和列映射，再选择已有词书或用文件名新建。再次导入同一本词书时只追加新词。每张卡片属于一本词书，不同词书的同词卡片各自记录进度。多本词书可以同时启用，新词按书轮流出现。
2. 每天先复习再学新词：上次没答对的词先回炉，其次是按间隔到期的词。
3. 新词先选释义，隔几题再无提示回想。选项不足时先看一次释义。答错时查看释义，再重做当前题型。
4. 整组辨识结束后可以开始或跳过拼写；拼错的词会回到最短间隔，排到下次复习前面。
5. 复习先判断熟悉程度，模糊或忘记的词在同组补考。
6. 词条的「学习重点」标签可以直接用于筛选：导入和 CSV 过目时可以只保留含指定标签的行；听写自由练习也可以只取带「听辨」标签的词。

## 听写

听写是独立的练习线，入口在今日页的听写任务区，不依赖先做完一组题。听写新词和听写复习各自一张卡，点击后直接在今日页内开始。

- 每本词书可以分别打开「背诵」和「听写」，两个开关互不影响；`active` 仍是整本书的总开关。只开听写的词书不会出现在今日的学习与复习队列里。
- 每个词有两条独立进度：背诵轨 `progress` 和听写轨 `dictation`。听写答对推进听写阶梯，答错回到起点，背诵轨的 step、到期日和掌握状态完全不变。
- 今日页的「听写新词」和「听写复习」分别按「听写每日新词」和「听写每日复习上限」安排；听写区右上角的「自由练习」可以按词书、范围（全部 / 未掌握 / 只有「听辨」标签）和每组数量自行选题，不写听写进度。
- 每题自动播一次英文发音，只显示输入框；重播次数用完后按未听出处理。答错显示单词、释义和发音按钮，并在本轮末尾重考；本轮内重考只影响小结，不重复写入进度。
- 听写记录使用 `stage: "dictation"`，不参与词义掌握状态和导出统计。

## 复习规则

复习时先只给单词，自己判断，不先看答案：

| 选择 | 行为 |
|---|---|
| 认识 | 直接下一个词，不展开释义 |
| 模糊 | 看完详情后，继续做释义选择和看中文回想英文。完成后间隔退一档 |
| 忘记了 | 做完同组补考后，按最短间隔重新排期 |

间隔是一条约 120 天的阶梯：1 → 2 → 4 → 7 → 15 → 30 → 60 → 120 天。认识前进一档，模糊退一档，不认识回到起点。走到 60 天以上记为「已掌握」。

这条阶梯不是官方公开参数，是按不背单词宣称的艾宾浩斯曲线和「x 天后出现」的行为还原的近似实现。

每日新词量、每组新词量和每日复习上限在左下角「设置」调整；听写每日新词、听写每日复习上限、听写每组词数和每个词的重播次数也在那里设置。用数字键选答案或自评，答后按空格或回车继续。

## 数据

词书、卡片和复习记录保存在 macOS 的 `~/Library/Application Support/com.jacoryspace.meletia/library.json`。删除词书会删除书里的卡片和复习记录。合并前可以预览重复数，同词保留目标书的释义和进度。

## 开发与打包

在 Mac 上准备 Xcode 命令行工具、Rust 和 Node.js 20 或更新版本，然后执行：

```sh
npm ci
npm test
npm run tauri dev
npm run tauri build -- --bundles app,dmg
```

应用和磁盘映像位于 `src-tauri/target/release/bundle/`。开发构建用于本机试用。公开分发前按 Apple 的要求设置签名与公证。
